# UX batch 177-182: Power Query and import look like Power BI

Planned by Claude Opus 5.5 (Team-Planner). Coded by Antigravity (177, 178, 179, 182) and OpenCode (180, 182 part). Reviewed and tested by Sonnet 5.5 (Team-Thinker).

## Tasks
- **177 Choose Columns dialog.** The ribbon Choose Columns opens a dialog like Power BI's: "(Select All Columns)" tristate, search, Sort A to Z / Original Order, every column checked by default, and output in the original column order.
- **178 Custom Column formula help.** New analytics_studio/m_intellisense.py `complete_m`. A syntax status line (uses compile_m_formula) and a completion popup for columns and M functions; a `[` inside a string literal does not trigger completion.
- **179 Excel import Navigator.** Excel import opens a Navigator: tree with search, Display Options, Select multiple items, a preview title, and collapsible Advanced options. Buttons are Load | Transform Data | Cancel. Load imports only the checked sheets and reports per-sheet failures. Type markers show only in the Navigator preview.
- **180 CSV import options.** "File Origin" with code-page labels; Colon delimiter.
- **182 Column header menus.** Right-click menu on a column header, and a type-icon click that opens Change Type, both like Power BI. Multi-selection is kept; a no-op type change is skipped; Remove Other Columns and Move work.
