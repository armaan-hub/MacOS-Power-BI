# Task 176: Power Query filter lists (null) separately from empty text

**Problem (user report 2026-11-16):** the column filter dropdown in the Power Query editor did not show null.

**Cause:** `_column_distinct_values` folded null and empty text into one "(Blank)" entry, filtered with is_blank / is_not_blank.

**Change:**
- Null is its own "(null)" entry, filtered with is_null / is_not_null (`[Col] <> null`).
- Empty text is an ordinary value labelled "(Blank)", filtered with equals / not_equals "".
- Unchecking one keeps the other's rows, as in Power BI.
- Two assertions in tests/test_power_query_column_menu_lifecycle.py were updated with the Planner's approval, because the behaviour changed on purpose.

**Open:** Power BI's exact label for empty text has not been checked on the guest yet. Minor: in a column with more than 1000 distinct values, "" can fall outside the listed 1000.

**Tests:** tests/test_ux176_filter_null.py. Team-Thinker drove the real panel and checked the M round trip.
