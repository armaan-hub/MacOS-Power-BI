# Task 175: DAX IntelliSense lists qualified columns for a bare name

**Problem (user report 2026-11-16):** typing a name in a measure did not show the table's columns as Power BI does.

**Cause:** `dax_intellisense._complete_identifier` offered functions, keywords, tables and measures, but no columns.

**Change:** for a non-empty prefix, every table's columns are ranked by column name and offered fully qualified (`'Sales Data'[Quantity]`, `Dates[When]`). Accepting one inserts the qualified reference. Ties sort by the qualified label, so functions with the same prefix (DATE, DATEADD) keep their order.

**Dropped from the brief:** listing a table's measures after `Table[`. Existing tests lock columns-only, and Power BI's exact behaviour there is not yet measured.

**Tests:** tests/test_ux175_intellisense_columns.py. The Team-Thinker real-app check (offscreen formula bar): `Qua` opens the popup with `Orders[Quantity]` first, and Tab inserts it.
