# Task 196: Power BI's Replace Values dialog

Planned by Claude Opus 5.5 (Team-Planner), coded by Antigravity, fixed, reviewed and tested by Sonnet 5.5 (Team-Thinker).

- Replace Values now opens a modal dialog, `ReplaceValuesDialog`, objectName "powerQueryReplaceValuesDialog".
- The dialog has three fields: Value To Find, Replace With, and Advanced options (Match entire cell contents).
- Step shape: `{"op":"replace_value","column","value","replacement","replacer":"value"|"text"}`. Values are typed. A step without "replacer" means "value".
- Engine:
  - Matching is exact by kind, so the number 5 no longer matches the text "5".
  - null can be found and replaced.
  - "text" does a case-sensitive substring replacement. It refuses non-text cells and an empty value to find.
- M uses typed literals, null, and Replacer.ReplaceText or Replacer.ReplaceValue. Examples:
  - `Table.ReplaceValue(#"Changed Type", "Fr", "ZZ", Replacer.ReplaceText, {"Particulars"})`
  - `Table.ReplaceValue(#"Replaced Value", 75, 12345, Replacer.ReplaceValue, {"Quantity"})`
- Sonnet fixes:
  - An empty ReplaceText value is now refused. It used to give "-a-b-c-".
  - Values are now validated.
  - Selecting a numeric step no longer crashes with a TypeError.
  - Large whole numbers no longer lose precision going through float.
  - Merged with the new Group By dialog code, so both gear routes are kept.
- Authorised test edits, each with a comment:
  - The replace_value row was removed from the lifecycle dialog-fields table.
  - The replace_value case was removed from the m_editor step-settings test.
- New test file: tests/test_ux196_replace_values_dialog.py (19 tests).
- Backlog, VM checks:
  - an empty ReplaceText value;
  - a null replacement with ReplaceText;
  - columns of type any or with no type;
  - NBSP is written raw instead of #(00A0).
