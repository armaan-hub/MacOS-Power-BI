# Task 72: statistical iterator audit (stats-audit-62)

An audit grid of 1,500 statistical and financial expressions was probed on Power BI (scratchpad t72a/pb.json). It covers STDEVX, VARX, MEDIANX, GEOMEANX, PRODUCTX, PERCENTILEX, XIRR, XNPV and NORM.DIST over filtered tables. Main gets 3 of them wrong; all 3 are in GEOMEANX.

Rule from the evidence: GEOMEANX/GEOMEAN of n values whose product is negative returns NaN when n is even and the real (negative) n-th root when n is odd. Main returns the signed root for even n too. Examples:
- `CALCULATE(GEOMEANX(ALLSELECTED(Facts),Facts[Quantity]-2.5),Facts[Region]="West")`: values 0.5 and -2.5. Power BI gives NaN; we give -1.118.
- The same expression under `Note="Paid"`: values -0.5, -1.5 and -2.5. Power BI gives -1.2331; we already match.
