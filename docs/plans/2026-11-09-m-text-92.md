# Task 102 (Iteration 191): Power Query Text function family (m-text-92)

First function family of the Power Query track. Power BI's 41 `Text.*` functions (list in
`docs/plans/2026-11-08-power-query-functions-pbi.txt`) in the M engine `analytics_studio/m_engine/` (stdlib).

**Spec:** `docs/plans/2026-11-09-m-text-92-spec.json` — 272 live Power BI answers (canonical text; compare
`evaluate_to_text(expr)` for exact equality). Opus keeps a further held-out set that is not given to you.

## Scope
- All 41: AfterDelimiter, At, BeforeDelimiter, BetweenDelimiters, Clean, Combine, Contains, End, EndsWith, Format, From,
  FromBinary, InferNumberType, Insert, Length, Lower, Middle, NewGuid, PadEnd, PadStart, PositionOf, PositionOfAny, Proper,
  Range, Remove, RemoveRange, Repeat, Replace, ReplaceRange, Reverse, Select, Split, SplitAny, Start, StartsWith, ToBinary,
  ToList, Trim, TrimEnd, TrimStart, Upper.
- The library values these need: `Comparer.Ordinal`, `Comparer.OrdinalIgnoreCase` (as function values usable as the
  comparer argument), `Occurrence.First/Last/All` (0/1/2), `RelativePosition.FromStart/FromEnd` (0/1),
  `TextEncoding.Utf8/Utf16/Ascii/Unicode/BigEndianUnicode/Windows` (Power BI's numeric code-page values — verify in the spec
  or by `TextEncoding.Utf8` printed via the oracle if needed), and `Text.From`'s culture argument for `en-US` (already) plus
  any other culture the spec uses; unsupported cultures must be an explicit `ERR` that is never a wrong answer.
- Semantics: Power BI uses UTF-16 code units for lengths/positions (`"𝔘nicode"` has length 8); upper/lower are
  .NET invariant per code unit (see existing `Text.Upper`); `Text.Proper` follows .NET TextInfo.ToTitleCase rules as measured;
  argument errors use Power BI's exact messages from the spec.
- `Text.NewGuid()` returns a random lower-case GUID text (only its type and length are specified).
