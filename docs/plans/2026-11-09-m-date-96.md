## Key points
- Error messages only from the spec (generalise their pattern); never invent one.
- Clock-dependent functions (LocalNow, UtcNow, FixedLocalNow, IsInCurrent*/Next*/Previous*/YearToDate) must be an
  explicit ERR (refusal) — they cannot be reproduced against fixed answers. DateTimeZone.ToLocal also refuses
  (depends on the machine time zone).
- Format strings (.NET custom/standard) and cultures: model exactly what the spec shows (en-US default, de-DE, fr-FR,
  en-GB); any other culture or unknown format specifier must be an ERR, never a guess.
- Fractional seconds, 100-ns ticks, OLE-automation date numbers (Number.From / Date.From(number)), file times.
