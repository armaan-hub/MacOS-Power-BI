# Task 160 — dax-hunt-160: CONTAINSROW / IN value-type mismatch is a query-level error (batch 18)

Goal: Power BI rejects the whole query when CONTAINSROW, IN or a multi-column table-constructor comparison pairs values whose
types cannot be compared. Measured 2026-11-15 in Power BI Desktop: Text vs Integer/Number/Currency/True-False/Date fails both
ways, True/False vs Integer/Number fails, Integer/Number/Currency/Date are compatible with each other, BLANK and variant values
are compatible with everything. IFERROR does not catch it. Refusing is always better than guessing.
