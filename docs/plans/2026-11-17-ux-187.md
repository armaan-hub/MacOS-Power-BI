# Task 187: Advanced Editor — M syntax colours, and it always opens

Planned by Claude Opus 5.5 (Team-Planner), coded by Antigravity, reviewed and tested by Sonnet 5.5 (Team-Thinker).

- MSyntaxHighlighter (m_code_editor.py) uses Power BI's Advanced Editor colours:
  - keywords: blue #0000FF
  - strings and #"names": #A31515
  - // and /* */ comments: green #008000
  - numbers: #098658
  - #date/#table intrinsics: #001080
- Block state is kept across lines for multi-line comments and strings. Keywords inside strings or comments, and inside identifiers such as eachRow or Table.SelectRows, are not coloured. 2,000 lines highlight in 0.03 s.
- When some steps cannot be shown as M, the Advanced Editor opens read-only instead of refusing. It shows the M for the supported prefix, then a `// Step N (operation): message` line for each issue; Done is disabled. The Append refusal is unchanged.
