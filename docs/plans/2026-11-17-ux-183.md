# Task 183: Applied Steps right-click menu like Power BI

Planned by Claude Opus 5.5 (Team-Planner), coded by Antigravity, reviewed and tested by Sonnet 5.5 (Team-Thinker).

- Right-clicking a step in Applied Steps opens a menu with: Edit Settings, Rename, Delete, Delete Until End, Insert Step After, Move before, Move after, Extract Previous, View Native Query, Properties.
- Delete, Move before and Move after follow the enable state of the remove, up and down buttons, so protected sparse helper steps cannot be deleted or moved.
- Delete Until End asks for confirmation. It is disabled for a protected step and stops if a removal does not shrink the list, so it cannot loop.
- Insert Step After, Extract Previous and View Native Query are disabled with a "Not supported yet" tooltip. Insert Step After is on the backlog.
- Real-app run: Move after, Move before and Delete Until End gave the expected step lists.
