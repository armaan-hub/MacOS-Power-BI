# Task 161 — dax-hunt-161: financial function precision (batch 19)

Goal: Power BI computes every financial function in IEEE double and shows 15 significant digits. The app leaked 28-digit
Decimals and exact binary expansions out of financial results, and INTRATE / YIELDDISC lost digits to cancellation.

Spec: 4388 measured expressions (financial families). None is read by the app.

Work (Haiku 5.5 coded; Sonnet 5.5 headed review and testing with three parallel read-only Haiku testers):
- analytics_studio/dax_bonds.py: INTRATE = (redemption - investment) / investment / fraction and
  YIELDDISC = (redemption - price) / price / fraction (the old x/y - 1 form cancelled digits).
- analytics_studio/measures.py: annuity, depreciation and dollar functions (PMT, PV, FV, NPER, RATE, IPMT, PPMT, CUMIPMT,
  CUMPRINC, ISPMT, SLN, SYD, DB, DDB, VDB, NOMINAL, RRI, PDURATION, DOLLARDE, DOLLARFR) are static Doubles unless a Currency
  amount makes them Currency (Task 150 rule, checked first); ABS keeps every digit of a Double (copy_abs).
- tests/test_iteration250_hunt_161.py: 6 tests with the measured values.

Testers: targeted pytest 522 passed; per-row scorer 0 newly wrong vs base; real app values unchanged except the fixed rows,
Currency arguments still Currency, the exit-time Qt segfault of the probe script also happens on base.

Left as known limits: PPMT / CUMIPMT last digit (about 70 formula orders tried) and the YIELD / ODDFYIELD solver stop rule
(Task 162 tried secant and Newton variants, about 100 combinations, none matched; no change). Unmeasured: NPER with Currency
arguments is static Double.
