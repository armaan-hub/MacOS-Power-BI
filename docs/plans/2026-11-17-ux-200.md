# Task 200: Pivot Column dialog like Power BI

Planned by Claude Opus 5.5 (Team-Planner), coded by Antigravity, reviewed and tested by Sonnet 5.5 (Team-Thinker). Source: Microsoft Learn "Pivot columns".

- Transform > Pivot Column opens a modal `PivotColumnDialog` (objectName powerQueryPivotColumnDialog, title "Pivot Column"): text `Use the names in column "<col>" to create new columns.`, a Values Column combo (other columns, table order), and a collapsed Advanced options section with Aggregate Value Function: Don't aggregate, Count (All), Count (Not Blank), Minimum, Maximum, Median, Sum, Average.
- Default aggregation is Sum, as in Power BI (the old form defaulted to Don't aggregate).
- Gear-edit opens the dialog prefilled and expands Advanced when the aggregation is not Sum. With no column selected it falls back to the first column, like Replace Values.
- Step schema, engine and M are unchanged. No existing tests changed. New tests: tests/test_ux200_pivot_column_dialog.py (6).
