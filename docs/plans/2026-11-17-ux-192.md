# Task 192: "Column tools" contextual ribbon tab in Table view

Planned by Claude Opus 5.5 (Team-Planner), coded by Antigravity, reviewed and tested by Sonnet 5.5 (Team-Thinker).

- Selecting a column in Table view shows a contextual **Column tools** tab and switches to it, as Power BI does. With no column selected, the tab is hidden. Table tools is unchanged.
- **Summarization** (`columnToolsSummarization`) and **Sort by column** (`columnToolsSortBy`) call the same controller slots as Model view's column inspector, so a change in either place shows in the other.
- **Data type** is a combo of the column's real type, through the existing type-change slot. "Any (mixed)" is not offered, and the combo never shows a stale index.
- **New column** and **Manage relationships** reuse the existing commands.
- These are disabled, each with a tooltip saying it is not supported yet: Name (rename), Format and `$ % , .00`, Data category, Data groups.
- Tests: tests/test_ux192_column_tools.py.
