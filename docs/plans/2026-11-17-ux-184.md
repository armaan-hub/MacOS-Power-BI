# Task 184: Data pane lists every table, grouped and collapsible, like Power BI

Planned by Claude Opus 5.5 (Team-Planner). Coded by Antigravity, then finished by Haiku 5.5 when Antigravity's quota ran out, with the final fix from Sonnet 5.5 after Haiku failed the same item twice. Reviewed and tested by Sonnet 5.5 (Team-Thinker), three rounds.

- New controller property `fieldTree`, plus slots setTableExpanded, focusTable, expandAllTables, collapseAllTables and toggleFieldInVisual. `filteredFields` is unchanged.
- The Data pane and the report Fields pane show every table with a chevron. Tables are sorted A to Z. Columns and measures sit under their home table. Hidden fields are left out. Search filters across tables and expands the tables that match. Each field has an add-to-visual checkbox.
- A column from a table that is not active can be added to the selected visual. Same-named columns in two tables stay separate: objectNames and inVisual carry the table id. Measure rows keep plain names, because measure names are unique in the model.
- selectTable expands the chosen table without collapsing the others. The table selectors call focusTable, which leaves only the chosen table expanded.
- The tree is cached. Its key covers the table catalog, headers, column types, measures, expansion and visual state.
- create_measure is unchanged from main. Power BI puts a new measure in the selected table.
