# Fluent System Icons

This directory contains a curated set of 20 px regular SVG assets from Microsoft's `@fluentui/svg-icons` package, version 1.1.343. Palette variants are generated from those assets by setting the SVG fill color. The icons are used locally by the QML shell; the application does not install or load the npm package at runtime.

Upstream: https://github.com/microsoft/fluentui-system-icons
